# Demo Pack

This folder contains synthetic demo guidance only. Do not place real invoices, customer records, tax IDs, bank details, or secrets here.

## Structure

- `invoices/`: reserved for fully synthetic sample invoices.
- `expected/`: scenario expectations used by humans and lightweight checks.
- `scenarios/`: presenter notes for repeatable demo paths.

Use obvious fictional labels only, such as:

- `APFlow Demo Supplier Ltd.`
- `DEMO-INVOICE-1001`
- `PO-DEMO-1001`
- `DEMO-TAX-0001`

The dashboard also exposes a generated fake PDF for upload demos.
